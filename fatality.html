Fatality Investigation Framework

A structured process for tracing incidents from trigger to fatal outcome

Purpose

This framework organizes scuba fatality analysis into repeatable stages so each case can be evaluated consistently. It supports your network findings by separating initiation events from downstream physiological failure.

Five-step framework

Step 1 — Define incident context

Capture setting variables first: location, depth range, conditions, diver profile, equipment configuration, and dive phase.

Step 2 — Identify trigger

Determine the initiating disruption (medical event, equipment issue, ascent/buoyancy problem, behavior factor, or environment factor).

Step 3 — Map mechanism of injury

Trace how the trigger turned into harm (gas/breathing compromise, pressure injury, panic cascade, cardiovascular stress, or trauma pathway).

Step 4 — Record disabling injury

Identify the incapacitating condition that removed self-rescue capacity (respiratory failure, cardiovascular/neurological collapse, pressure injury, etc.).

Step 5 — Confirm final cause and intervention window

Document final cause of death and note where prevention or rescue could have interrupted progression.

How to use it with your data

  • Code each case into the same stage order for comparability across years.
  • Quantify pathway weights between stages to locate high-frequency routes.
  • Separate prevention targets (early stage) from rescue targets (late stage).
  • Track unknown categories explicitly so reporting quality can be improved over time.

In your current project, this framework aligns directly with the strongest network results: repeated convergence toward drowning after respiratory and cardiovascular disabling pathways.
